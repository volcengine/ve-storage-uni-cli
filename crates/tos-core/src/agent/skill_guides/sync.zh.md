## 同步决策

- 本地目录通过 `cp --recursive` 或 `sync` 上传时，默认保留匹配的目录，包括空目录。`--disable-dir-object` 跳过显式目录上传，仅适用于本地目录上传方向；HNS/ADrive 的文件仍可能自动创建所需父目录。FNS 用以 `/` 结尾的零字节对象表示目录，HNS 目录使用 STANDARD，不套用文件的存储类型覆盖。普通清单和 `--no-manifest` 模式遵循相同目录规则。空源目录会创建可表达的目标文件夹，桶或空间根不创建空 Key；`--include-parent` 保留源目录名。目录计入项目数，字节数为零。关闭目录上传不会授权 `sync --delete` 删除源端仍存在的目录。
- 这是以源为准的单向操作，并非双向冲突合并。执行前检查源/目标方向、递归相对路径、`--include-parent` 及包含/排除过滤器。
- 不带 `--delete` 时保留目标独有项目；`--delete` 开启目标清理并提高确认要求，启用前用 `--dry-run` 检查准确目标范围。预览可能未完成发现，不能证明已列出全部待删除项目。
- 已有文件需要保护时明确选择 `--overwrite-strategy`。`newer` 比较时间戳，不做逐字节校验；实际配置与后端共同决定传输行为。
- 传输失败会阻止后续目标清理阶段。部分成功后可能同时存在已复制项目与保留的多余项目，重试前检查汇总及报告。
- `--report-path` 保留结果，`--manifest-path` 保留计划项目；`--no-manifest` 改用流式发现并放弃完整清单输出。核验目标应有项目、失败数量，以及仅在授权 `--delete` 时检查目标多余项目的清理结果。

- 目录过滤前移除末尾 `/`。ADrive 的过滤路径包含保留的父级段；TOS sync 沿用目标映射前的源相对路径过滤。选中文件的祖先目录受到保护，有效目标根始终作为结构容器保留。
