## 移动工作流程

- 移动会修改两端并可能删除源。先解析最终目标，目录形式的目标可能追加源文件名；执行前排除源和目标相同或范围重叠的情况。
- 目录/前缀使用 `--recursive`，检查 `--include-parent`、`--include`、`--exclude` 与预期相对路径是否一致。实现可能使用支持的重命名，也可能先复制再删除源；不能假定跨文件或跨服务原子完成。
- 检查 `--dry-run` 及命令确认要求；`--force` 不代表已获得用户授权。在流程允许时保留源，直到预期传输得到核验。
- 递归 `--report-path`、`--manifest-path` 可区分复制和删源操作。失败后逐项检查；复制成功而删除失败时，两端可能同时保留文件，不要直接重跑整个移动或删除所有残余源。
- 先核验目标名称、大小，再核验应删除的源项目确已移除，不能仅凭目标存在判断移动完成。
