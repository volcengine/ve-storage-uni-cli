## 删除工作流程

- 删除前确认具体对象/文件或递归前缀/文件夹。检查 `--dry-run`、目标规范化、过滤器和确认要求；影响范围未知或截断的预览不是完整删除清单。
- `--recursive` 仅用于预期子树。过滤器支持取决于后端及删除模式，不能假定直接递归删除会遵守包含/排除过滤；选择策略前阅读参数契约。
- 只有用户任务包含清理未完成分片上传时才添加 `--include-uploads`，因为它会扩大受影响资源范围。
- 批量删除保留 `--report-path`，检查失败和跳过项目，再次列举目标。非零退出码可能发生在部分项目已删除之后，只重试仍在授权范围内的剩余项目。删除文件/对象不等于删除其所属 Bucket 或空间。
